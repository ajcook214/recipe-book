DriveAdapter on real Google Drive

The adapter contract that npm test runs against a fake Drive, run here against your real one. Signing in opens a Google window asking to let Recipe Book use the files it creates in your Drive, and nothing else. The token stays in this page and is gone when you close it.

Each run writes to a folder of its own under My Drive / RecipeApp-tests /, one subfolder per test, well away from RecipeApp/. The files stay there for you to open by hand. Delete RecipeApp-tests in the Drive web UI when you are done; the API refuses to trash it (see docs/roadmap.md, known gaps). Expect a minute or so and a few hundred requests.
